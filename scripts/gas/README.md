# GAS 橋渡しの設置手順（Gmail[BLOG] → Drive）

メールに添付した写真と本文を、Google ドライブの `BabaBlog-Inbox/` に自動保存する
Google Apps Script の設置手順です。設置後は「写真添付メールを送るだけ」で運用できます。

## 0. 実行アカウント: nozawa@beyonds.ai（決定）

GAS は **nozawa@beyonds.ai** で作成します（方式B）。Gmail・Drive コネクタと同じ
アカウントなので、フォルダ共有などの追加設定は不要です。
[BLOG] メールも **nozawa@beyonds.ai 宛**に送ってください。

## 1. 事前準備は不要（差出人＋宛先で判定）
このスクリプトは **`goemonama@gmail.com` から `nozawa@beyonds.ai` 宛（TO）に届いたメール**を、
件名に関係なく**すべて**対象にします（`Code.gs` 先頭の `FROM_ADDRESS` / `TO_ADDRESS` で変更可）。
合言葉「ばばろぐ」を件名に書く必要はもうありません（書いてあっても店名の判定時に自動で取り除きます）。

ラベルやフィルタの設定は不要です。処理済みの目印として `blog-done` ラベルをスクリプトが自動作成・付与します。

### ブログにしたくないメールを送るとき
件名に **`非公開` / `skip` / `スキップ` / `ブログ不要`** のどれかを入れると対象外になります
（`Code.gs` の `SKIP_WORDS`）。CCやBCCで送った場合（TOが `nozawa@beyonds.ai` でない場合）も対象外です。

## 2. Apps Script プロジェクトを作る
1. 上記で決めたアカウントで [script.google.com](https://script.google.com) を開く。
2. 「新しいプロジェクト」を作成。
3. `Code.gs`（このフォルダの中身）を丸ごと貼り付けて保存。
4. プロジェクト名は「BabaBlog Bridge」などに。

## 3. 権限を承認して動作確認
1. 関数選択で `processBlogEmails` を選び ▶ 実行。
2. 初回は Gmail / Drive へのアクセス承認を求められるので許可。
3. テスト用に、自分宛に件名 `[BLOG] テスト店` で写真添付メールを送ってから実行 →
   Drive に `BabaBlog-Inbox/<日付>_テスト店/` ができ、`memo.txt`・`meta.json`・画像が入っていればOK。

## 4. 自動実行をオンにする
関数選択で `installTrigger` を選び ▶ 実行。
→ 15分おきに `processBlogEmails` が自動で回ります（頻度は `installTrigger` 内で変更可）。

## メールの書き方（運用）

```
差出人: goemonama@gmail.com
宛先(TO): nozawa@beyonds.ai
件名: 店名だけ            ← 例「てけてけ」。合言葉「ばばろぐ」は不要
本文:
カテゴリ: ごはん          ← ごはん / 子育て / 旅
場所: 高田馬場
6月5日                     ← 任意。本文に日付を書くと訪問日として使われる（省略時は送信日）
メモ: 金曜の夜に家族4人で。タンとカルビが旨かった。子連れOK。
（写真は添付するだけ）
```

- **件名は原則「店名だけ」**。それ以外の情報（カテゴリ・場所・日付・感想）は本文に書く。
- ただし件名に日付が混ざっても大丈夫。`7/22 てけてけ` `7月22日 てけてけ` `2026/7/22 てけてけ` のように
  書いても、日付は自動で切り離して**訪問日**として使い、残りを店名として扱う。
  年を省いた場合は「今日以前で最も近い年」で解釈する。
- 店名以外がタイトルになるケース（買ってよかったグッズなど）は、件名にそのテーマを書けばそのまま使われる。
- 本文の `カテゴリ` `場所` `メモ` は任意だが、あると記事の精度が上がる。

## 変更を反映するとき（重要）

`Code.gs` はこのリポジトリに置いてあるだけで、**GitHubへpushしても動いているスクリプトは更新されません**。
中身を変えたら、[script.google.com](https://script.google.com) の「BabaBlog Bridge」プロジェクトを開き、
`Code.gs` を丸ごと貼り替えて保存してください（トリガーの再登録は不要）。

## 保存されるもの（後段Claudeが読む形）

```
BabaBlog-Inbox/
└─ 2026-06-21_馬場焼肉ホルモン/
   ├─ memo.txt        # 人間用：件名・日時・本文
   ├─ meta.json       # 機械用：shop_hint, body, date_iso, status:"pending" ...
   ├─ 01.jpg          # 添付写真
   └─ 02.jpg
```

後段は `status:"pending"`（= `published.txt` がまだ無い）フォルダだけを処理し、
公開後にそのフォルダへ `published.txt` を置いて二重投稿を防ぎます。
